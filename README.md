🥖 Panadería Los 5 Hermanos

Bienvenido al repositorio de la página web de Panadería Los 5 Hermanos, un sitio desarrollado para presentar nuestros productos, compartir nuestra historia y facilitar el contacto con nuestros clientes.

📋 Descripción

Este proyecto consiste en una página web moderna y responsive diseñada para una panadería familiar. El objetivo principal es ofrecer una experiencia simple, atractiva y accesible para que los usuarios puedan conocer nuestros productos y realizar consultas de manera rápida.

✨ Características
Diseño adaptable a dispositivos móviles, tablets y computadoras.
Catálogo de productos de panadería y pastelería.
Sección "Sobre Nosotros".
Formulario de contacto.
Galería de imágenes.
Navegación intuitiva y amigable.
Optimización para motores de búsqueda (SEO).
🛠️ Tecnologías Utilizadas
HTML5
CSS3
Sass
